# Station metadata

This directory contains `stations.txt`, a local copy of a station metadata table published through the [NSF National Center for Atmospheric Research (NSF NCAR) Research Applications Laboratory Real-Time Weather site](https://weather.ral.ucar.edu/surface/).

Although the table supports the site’s Meteorological Aerodrome Report (METAR) interface, it is not limited to METAR stations. Its header states that it was compiled from lists of METAR, Next Generation Weather Radar (NEXRAD), rawinsonde, wind-profiler, weather-office, aviation, and legacy surface-observation sites.
